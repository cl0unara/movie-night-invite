# Киновечер

Отдельная статическая страница-приглашение. Не связана с проектом Sfera.

## Запуск на компьютере

Можно открыть `index.html` напрямую или запустить локальный сервер:

```powershell
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Ответ на приглашение

После выбора фильма, даты и времени страница откроет окно отправки Telegram с готовым текстом. Нужно выбрать чат и нажать «Отправить». Для этого не нужны бот и токен. До отправки текст никуда не передаётся.

## Публикация через GitHub Pages

Создай отдельный репозиторий для этой папки и загрузи её содержимое. В настройках репозитория открой **Settings**, затем **Pages**, выбери источник публикации **Deploy from a branch**, ветку `main` и папку `/ (root)`. После публикации страница будет доступна по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Если нужен репозиторий без открытого кода, выбери приватный. Доступность GitHub Pages для приватного репозитория зависит от плана аккаунта.
